02 / Components

组件

按钮、输入、头像、反馈与附件菜单都复用现有 DOM 结构，只替换视觉层；交互逻辑保持原样。

按钮
主操作使用品牌渐变，次操作保持中性。
PRIMARY / SECONDARY / GHOST
SIZE / ICON / DISABLED

主按钮只用于当前视图的唯一主动作，危险操作保持低饱和。

表单与切换
输入控件使用统一的焦点环与 10px 圆角。
头像与状态
头像保持低饱和；在线状态使用单一绿色信号。
